# Sign-up Form

A simple and clean sign-up form built as part of **The Odin Project** Intermediate HTML & CSS course.

## 📌 Overview

This project recreates a modern sign-up page from a design mockup. It focuses on structuring forms properly and applying CSS styling to create a polished user interface.

## 🎯 Purpose

To practice core front-end fundamentals by:
- Building and structuring HTML forms
- Styling layouts with CSS
- Applying input states using pseudo-classes (`:focus`, `:invalid`)
- Working with images and external fonts

## 🛠️ Tech Stack

- HTML5  
- CSS3
